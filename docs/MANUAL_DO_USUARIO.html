Guia prático para instalação, execução local e gerenciamento do acervo de livros.

1. Visão Geral da Aplicação

O Littera é uma aplicação web para gerenciamento e consulta de coleções literárias pessoais. O sistema permite cadastrar, listar, pesquisar, filtrar por gênero, visualizar detalhes, atualizar e excluir livros através de uma interface elegante e responsiva.

2. Pré-requisitos e Execução Rápida

Configuração Zero: O Littera já possui o banco de dados SQLite e o servidor Tomcat 10 embutidos. Basta ter o Java 17, 21 ou 22 instalado no computador.

Como Iniciar o Servidor:

  1. Abra a pasta Littera App;
  2. Execute o arquivo run.bat (ou no PowerShell: .\run.ps1);
  3. Aguarde a mensagem de confirmação no terminal e abra seu navegador em: 
    http://localhost:8080/livros
  4. Para encerrar a execução a qualquer momento, pressione Ctrl + C na janela do terminal.

3. Guia de Funcionalidades

3.1. Navegação Geral

A barra lateral esquerda contém a marca L. LITTERA e o ícone de livros. Clicar em qualquer ponto da barra redireciona para a coleção.

3.2. Busca e Filtragem por Gêneros

  • Busca por Título ou Autor: Digite uma palavra no campo superior e pressione Enter. A busca é instantânea e não diferencia maiúsculas de minúsculas.
  • Filtro por Gênero: Clique nas pílulas de categorias (Todos, Romance, Ficção, Filosofia, etc.). A pílula verde limão indica a categoria ativa.

3.3. Adicionar Novo Livro

  1. Clique no botão "+ Adicionar livro" no topo direito;
  2. Preencha o Título, Autor e selecione o Gênero (campos obrigatórios);
  3. Opcionalmente, informe o Ano de publicação, Número de páginas e Sinopse;
  4. Clique em "Adicionar livro". O sistema valida os campos e abre a tela de detalhes da nova obra.

3.4. Detalhes, Edição e Exclusão

  • Detalhes: Clique no cartão de qualquer livro na tela principal para abrir a página detalhada com o selo Na coleção, metadados e sinopse completa.
  • Editar Livro: Na tela de detalhes, clique em "Editar livro", modifique as informações e clique em "Salvar alterações".
  • Excluir Livro: Clique no botão branco "Excluir livro". Uma caixa de diálogo modal de segurança solicitará sua confirmação antes de remover o registro.

4. Dúvidas Frequentes (FAQ)

  • Onde os dados são salvos? Os dados são persistidos no arquivo littera.db no diretório da aplicação.
  • Suporta acentuação em português? Sim, toda a aplicação opera sob codificação UTF-8 nativa.
